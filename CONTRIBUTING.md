# Contributing

Reports from other Lenovo models are the most useful thing right now. Open an issue with the model and machine type (e.g. 83F0), BIOS version, the output of `tools/cbmr-status.sh`, and a panic report if you had the `vm_page_validate_no_references` panic.

Pull requests: keep them small and say how you tested them. I read and test every PR before merging. AI-assisted PRs are fine as long as you can explain the change, which is the same bar I hold my own code to.
